# Message Examples

## Morning briefing

- market setup with key indices, rates, oil, gold, bitcoin, and dollar context
- top themes driven by clustered catalysts
- sector scan with major names and read-through
- earnings calendar
- watchlist section

## Intraday update

- compact market snapshot
- only the highest-ranking new catalysts or material updates
- each item includes type, confidence, and reason code

## Breaking alert

- one high-threshold event
- why it matters
- confidence and market context
